Movie Recommendation System 🎬

A smart and multi-algorithm movie recommendation engine built with Python and Streamlit. This system provides personalized movie suggestions using:

- Content-Based Filtering - Finds similar movies based on genres, cast, crew, and plot
- Item-Based Collaborative Filtering - Uses user rating patterns for recommendations  
- Matrix Factorization (SVD) - Predicts ratings using advanced matrix decomposition
- Popularity-Based - Suggests top-rated unwatched movies

*Key Features:
- Clean Arabic UI with Streamlit
- Multiple recommendation algorithms
- Real TMDB dataset (5000+ movies)
- Model evaluation and performance metrics
- Interactive web interface

*Tech Stack: Python, Pandas, Scikit-learn, Streamlit, TF-IDF, Cosine Similarity, SVD.
